Here is the code for the CI/CD pipeline:

**pipeline.py**
```python
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import mlflow
import logging

def load_data(file_path):
    try:
        data = pd.read_csv(file_path)
        return data
    except Exception as e:
        logging.error(f"Error loading data: {e}")
        raise

def preprocess_data(data):
    try:
        # Select relevant features
        X = data[['PT08.S1(CO)', 'PT08.S2(NMHC)', 'PT08.S3(NOx)', 'PT08.S4(NO2)', 'PT08.S5(O3)', 'NOx(GT)', 'C6H6(GT)', 'T', 'RH', 'AH', 'Hour', 'DayOfWeek', 'Month']]
        
        # Encode categorical variables
        X['Hour'] = pd.Categorical(X['Hour']).codes
        X['DayOfWeek'] = pd.Categorical(X['DayOfWeek']).codes
        X['Month'] = pd.Categorical(X['Month']).codes
        
        # Scale data
        scaler = StandardScaler()
        X = scaler.fit_transform(X)
        
        # Split data into training and testing sets
        X_train, X_test, y_train, y_test = train_test_split(X, data['Anomaly'], test_size=0.2, random_state=42)
        
        return X_train, X_test, y_train, y_test
    except Exception as e:
        logging.error(f"Error preprocessing data: {e}")
        raise

def train_model(X_train, y_train):
    try:
        # Train RandomForest model
        model = RandomForestClassifier(n_estimators=100, random_state=42)
        model.fit(X_train, y_train)
        
        # Log model with MLflow
        mlflow.sklearn.log_model(model, "random_forest")
        
        return model
    except Exception as e:
        logging.error(f"Error training model: {e}")
        raise
```

**test_pipeline.py**
```python
import pytest
from pipeline import load_data, preprocess_data, train_model

def test_load_data():
    data = load_data('data/air_quality.csv')
    assert data is not None

def test_preprocess_data():
    data = load_data('data/air_quality.csv')
    X_train, X_test, y_train, y_test = preprocess_data(data)
    assert X_train is not None
    assert X_test is not None
    assert y_train is not None
    assert y_test is not None

def test_train_model():
    data = load_data('data/air_quality.csv')
    X_train, X_test, y_train, y_test = preprocess_data(data)
    model = train_model(X_train, y_train)
    assert model is not None
```

**.github/workflows/ci_cd.yml**
```yml
name: CI/CD

on:
  push:
    branches:
      - main

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2

      - name: Install dependencies
        run: |
          pip install -r requirements.txt

      - name: Run tests
        run: |
          pytest test_pipeline.py

      - name: Train model
        run: |
          python pipeline.py --file data/air_quality.csv

      - name: Log model with MLflow
        run: |
          mlflow sklog --experiment-name air_quality --artifact-path model.pkl

      - name: Deploy model
        uses: appleboy/ssh-action@v0.6.0
        with:
          host: ${{ secrets.HOST }}
          username: ${{ secrets.USERNAME }}
          password: ${{ secrets.PASSWORD }}
          script: |
            mv model.pkl /path/to/deployment/location
```

Note that you'll need to replace the `secrets` placeholders in the GitHub Actions YAML with your actual deployment credentials.

Also, this is just a basic example to get you started. You may want to add more error handling, logging, and testing to make the pipeline more robust.

You can also use other tools like Docker, Kubernetes, and AWS to deploy your model.

Make sure to commit and push the code to your GitHub repository, and then trigger the CI/CD pipeline by pushing a new commit to the `main` branch.
