Here's the code for the pipeline, test pipeline, and GitHub Actions YAML:

**pipeline.py**
```python
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import mlflow.sklearn
import logging

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

def load_data(file_path):
    try:
        data = pd.read_csv(file_path)
        return data
    except Exception as e:
        logger.error(f"Error loading data: {e}")
        raise

def preprocess_data(data):
    try:
        # Drop unnecessary columns
        data.drop(['Hour', 'DayOfWeek', 'Month'], axis=1, inplace=True)
        
        # Scale features
        scaler = StandardScaler()
        X = scaler.fit_transform(data.drop('Anomaly', axis=1))
        
        # Split into features and target
        y = data['Anomaly']
        return X, y
    except Exception as e:
        logger.error(f"Error preprocessing data: {e}")
        raise

def train_model(X_train, y_train):
    try:
        # Train a RandomForest classifier
        model = RandomForestClassifier(n_estimators=100, random_state=42)
        model.fit(X_train, y_train)
        
        # Log the model with MLflow
        mlflow.sklearn.log_model(model, "random_forest")
        
        return model
    except Exception as e:
        logger.error(f"Error training model: {e}")
        raise
```


**.github/workflows/ci_cd.yml**
```yml
name: CI/CD

on:
  push:
    branches:
      - main

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2

      - name: Install dependencies
        run: |
          pip install -r requirements.txt

      - name: Run tests
        run: |
          pytest test_pipeline.py

      - name: Train model
        run: |
          python pipeline.py train_model

      - name: Log model with MLflow
        run: |
          mlflow sklog -m RandomForest -p pipeline.py

      - name: Deploy model
        uses: appleboy/ssh-action@v0.3.0
        with:
          host: ${{ secrets.HOST }}
          username: ${{ secrets.USERNAME }}
          password: ${{ secrets.PASSWORD }}
          script: |
            # Copy model to server
            scp pipeline.py user@host:/path/to/model.py

            # Run model on server
            ssh user@host "python /path/to/model.py"
```

Note that you'll need to replace the `secrets` placeholders in the GitHub Actions YAML with your actual server credentials. Also, make sure to install the `mlflow` and `pytest` packages in your `requirements.txt` file.

This pipeline assumes that you have a `requirements.txt` file in your repository with the necessary dependencies. It also assumes that you have the `mlflow` and `pytest` packages installed.

When you push changes to the `main` branch, the pipeline will run automatically. It will first check out your code, install dependencies, run tests, train the model, log the model with MLflow, and finally deploy the model to your server.
