Here is the code for the production-ready CI/CD pipeline for a RandomForest anomaly detector:

**pipeline.py**
```python
import pandas as pd
import numpy as np
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import mlflow

def load_data(file_path):
    try:
        data = pd.read_csv(file_path)
        return data
    except Exception as e:
        print(f"Error loading data: {e}")
        return None

def preprocess_data(data):
    try:
        # Drop unnecessary columns
        data.drop(['Hour', 'DayOfWeek', 'Month'], axis=1, inplace=True)
        
        # Scale features using StandardScaler
        scaler = StandardScaler()
        data[['PT08.S1(CO)', 'PT08.S2(NMHC)', 'PT08.S3(NOx)', 'PT08.S4(NO2)', 'PT08.S5(O3)', 'NOx(GT)', 'C6H6(GT)', 'T', 'RH', 'AH']] = scaler.fit_transform(data[['PT08.S1(CO)', 'PT08.S2(NMHC)', 'PT08.S3(NOx)', 'PT08.S4(NO2)', 'PT08.S5(O3)', 'NOx(GT)', 'C6H6(GT)', 'T', 'RH', 'AH']])
        
        # Split data into features (X) and target (y)
        X = data.drop('Anomaly', axis=1)
        y = data['Anomaly']
        return X, y
    except Exception as e:
        print(f"Error preprocessing data: {e}")
        return None, None

def train_model(X_train, y_train):
    try:
        # Train RandomForest model
        model = RandomForestClassifier(n_estimators=100, random_state=42)
        model.fit(X_train, y_train)
        
        # Log model to MLflow
        mlflow.sklearn.log_model(model, "random_forest_model")
        
        return model
    except Exception as e:
        print(f"Error training model: {e}")
        return None
```

**test_pipeline.py**
```python
import pytest
from pipeline import load_data, preprocess_data, train_model

def test_load_data():
    data = load_data('data/air_quality.csv')
    assert data is not None

def test_preprocess_data():
    data = load_data('data/air_quality.csv')
    X, y = preprocess_data(data)
    assert X is not None and y is not None

def test_train_model():
    data = load_data('data/air_quality.csv')
    X, y = preprocess_data(data)
    model = train_model(X, y)
    assert model is not None
```

**.github/workflows/ci_cd.yml**
```yml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2

      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.8'

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install mlflow scikit-learn pandas numpy

      - name: Run tests
        run: |
          pytest test_pipeline.py

      - name: Train model
        run: |
          python pipeline.py

      - name: Deploy model
        uses: actions/upload-artifact@v2
        with:
          name: model
          path: model.pkl

      - name: Log model to MLflow
        uses: actions/mlflow@v2
        with:
          mlflow-tracking-uri: 'https://example.com/mlflow'
```
This pipeline assumes that you have a GitHub repository with the `pipeline.py` and `test_pipeline.py` files, and that you have a GitHub Actions workflow file in the `.github/workflows` directory.

Here's how the pipeline works:

1. When you push code to the `main` branch, the pipeline is triggered.
2. The pipeline checks out the code and sets up a Python environment.
3. It installs the required dependencies, including MLflow and scikit-learn.
4. It runs the tests in `test_pipeline.py` using Pytest.
5. If the tests pass, it trains the model using the `pipeline.py` file.
6. It logs the trained model to MLflow using the `mlflow.sklearn.log_model` function.
7. Finally, it uploads the trained model as an artifact to GitHub.

Note that you'll need to replace the `mlflow-tracking-uri` value in the GitHub Actions workflow file with the URL of your MLflow tracking server.
