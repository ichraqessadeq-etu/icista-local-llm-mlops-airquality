3. **GitHub Actions YAML**

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install pandas mlflow pytest

    - name: Test
      run: pytest test_pipeline.py

    - name: Train and Evaluate Model
      run: python pipeline.py

    - name: Upload Artifacts
      uses: mlflow/mlflow-action@v2
      with:
        track: dev
        artifact_path: .
```

This pipeline uses MLflow for model training and logging, and Pytest for testing. The GitHub Actions workflow is triggered on every push and pull request. It sets up Python, installs dependencies, runs tests, trains the model, and logs the model and metrics to MLflow.
