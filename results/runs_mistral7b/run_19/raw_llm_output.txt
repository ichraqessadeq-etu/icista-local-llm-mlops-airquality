3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Test
      run: pytest test_pipeline.py

    - name: Train and Log Model
      run: python pipeline.py --file data/air_quality.csv

    - name: Upload Artifacts
      uses: actions/upload-artifact@v2
      with:
        name: models
        path: mlruns/$(mlflow_run_id)
```

In this example, I've created a simple CI/CD pipeline using GitHub Actions. The pipeline checks out the code, sets up Python, installs dependencies, runs tests, trains the model, and logs the model artifact. The pipeline also uses MLflow to track the model's run and artifact.
