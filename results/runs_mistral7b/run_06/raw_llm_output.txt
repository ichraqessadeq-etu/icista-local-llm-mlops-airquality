3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Test
      run: pytest test_pipeline.py

    - name: Train and Log Model
      run: python pipeline.py data/air_quality.csv

    - name: Upload artifacts
      uses: actions/upload-artifact@v2
      with:
        name: model
        path: model.pkl
```

In this example, I assumed that you have a requirements.txt file listing your project dependencies. The pipeline.py file loads data, preprocesses it, trains a RandomForest model, and logs the trained model and some parameters using MLflow. The test_pipeline.py file contains unit tests for each function in the pipeline.py file. The GitHub Actions YAML file sets up a CI/CD pipeline that runs the tests and trains the model on each push or pull request. The trained model is then uploaded as an artifact.
