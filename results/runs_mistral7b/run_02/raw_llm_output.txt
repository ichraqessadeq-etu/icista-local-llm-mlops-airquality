3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Test pipeline
      run: |
        pytest test_pipeline.py

    - name: Train and log model
      run: |
        python pipeline.py --file data/air_quality.csv
```

In this example, I've used the RandomForestClassifier for anomaly detection, but you can replace it with any other suitable model. Also, I've used Pytest for testing, and GitHub Actions for CI/CD. The requirements.txt file should contain the necessary dependencies like pandas, sklearn, mlflow, and pytest.
