```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install pandas mlflow pytest

    - name: Test
      run: pytest test_pipeline.py

    - name: Train Model
      run: python pipeline.py

    - name: Upload artifacts
      uses: mlflow/mlflow-github-action@v1
      with:
        track_run: true
        mlflow_track_run_id: ${{ github.run_id }}
        mlflow_artifact_paths: pipeline/model
```

This pipeline uses MLflow for tracking the model and its metrics, and pytest for unit testing. The GitHub Actions workflow runs on every push and pull request, tests the code, trains the model, and uploads the trained model as an artifact.
